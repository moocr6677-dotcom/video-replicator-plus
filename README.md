# Video Replicator Plus

عايز اعمل  الفيديوهات زي كدا

النت تستخرج النص وتضيف الترجمة وتنسقالفروض اي فيديو اضيفوا يتعمل تلقائيًا



يكون زي الفيديو المرجعية تماما في أدق التفاصيل الاحجام والقياس وكل حاعايز دلكيتي اقدر احمل الفيديو الشاشة بالكامل هو والفيديو شغال والنص شغال زي نظام تسجيل شاشة بس للفيديو والنص واقدر احملو زي الفيديو المرجعي بالضبطجة
